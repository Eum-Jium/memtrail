# 화두태그 통제 어휘 (controlled vocabulary)

카드 생성 프롬프트에 주입되는 태그 목록이다. **이 파일이 유일한 편집 지점** —
사용자가 손으로 고치고, LLM 은 여기서 고르기만 한다.

왜 필요했나: 자유 생성으로 두었더니 카드 전수에서 **고유 태그 344개 중 279개(81%)가
단 한 번만 등장**했다 (2026-08-07 실측). `개발도구`/`개발 도구`, `머신러닝`/`기계학습`,
`문서`/`문서작성` 처럼 같은 것이 표기만 다르게 갈라졌고, 그 결과 `promote_thread` 승격
후보 판정(같은 태그 3회 이상)이 실제 빈도를 못 재게 됐다.

규칙:
- `##` 분류 헤더 **아래의** `-` 줄만 태그로 읽힌다 (이 서문 불릿은 안 읽힌다).
- 괄호 안은 흡수할 동의어 예시 (프롬프트엔 안 실린다, 표기 통일용 메모).
- 새 태그가 정말 필요하면 카드에 `(신규)` 표시로 나오고, 승격 후보 로그에 잡힌다.
  쓸 만하면 여기에 추가할 것.

> **아래는 출발용 예시다.** 태그는 본인의 대화 분포에서 나와야 쓸모가 있다.
> 카드를 몇 백 장 쌓은 뒤 `(신규)` 로그에 자주 잡히는 것들로 갈아엎는 걸 전제로 둔다.
> 분류 헤더(`##`)는 "본업 / 만드는 것 / 기반·도구 / 배움·나 / 생활" 정도의 축이면 충분하고,
> 한 축에 5~10개를 넘기지 않는 게 승격 판정에 유리하다.

## 본업
- 도메인지식 (전공, 업무 도메인)
- 회사업무 (보고, 회의, 일정)
- 운영 (일정, 협업)

## 만드는 것
- 기억시스템 (memex, 회상, 카드)
- 자동화 (워크플로우, 효율화, 스크립트)
- 앱개발 (앱, 웹앱, 배포)
- 데이터 (데이터분석, 데이터수집, 데이터검증)
- 머신러닝 (기계학습, 딥러닝)

## 기반·도구
- 인프라 (서버, 클라우드, 네트워크, 시스템관리)
- 하드웨어 (기기, 장비)
- 개발도구 (버전관리, 코드리뷰, 버그수정, 트러블슈팅, 코드품질, 환경설정)
- 보안
- 문서작성 (문서화)

## 배움·나
- 학습 (공부, 시험, 과제)
- 교육 (가르치기, 강의, 발표)
- 커리어 (진로, 경력, 자격)
- 인식론 (철학, 사고법, 호기심)

## 생활
- 가족
- 취미
- 재물 (돈, 금융)
- 일상
